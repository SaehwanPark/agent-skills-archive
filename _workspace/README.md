# Workspace Handoffs

Use this directory for temporary or reviewable harness artifacts produced while developing
skills in this repository.

Recommended names:

- `01_request_scope.md`
- `02_skill_draft.md`
- `03_validation_report.md`
- `04_review_notes.md`

Do not put deployable skills here. Archive skills belong under `skills/`; repo-local
harness skills belong under `.agents/skills/`.
