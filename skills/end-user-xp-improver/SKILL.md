# End-User Experience Improver

1. Identify who uses the workflow, what they need to accomplish, and where they lose time or get stuck. Use the interface, docs, and available support or test evidence. State consequential assumptions.
2. Improve the common path with familiar conventions, useful defaults, and fewer required decisions. Keep advanced options discoverable and preserve established behavior unless the task changes it.
3. Make feedback specific and actionable. Preserve input for retries where practical. For UI work, check keyboard and focus behavior, labels, contrast, and assistive semantics.
4. Verify the representative journey end to end, including relevant empty, waiting, permission, error, and recovery states. Report any checks that could not be exercised.
