# fp-developer skill package

This package contains an OpenAI agent skill for functional-first development across Python, Rust, Swift, Kotlin, and Mojo.

## Structure

```text
fp-developer/
  SKILL.md
  README.md
  references/
    checklists.md
    review-protocol.md
    python.md
    rust.md
    swift.md
    kotlin.md
    mojo.md
  examples/
    review-summary-template.md
```

`SKILL.md` contains the activation criteria, core workflow, and links to reference files. Language-specific details live in `references/` so they can be maintained independently.
