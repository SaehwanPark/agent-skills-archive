# Lesson Documenter

- Confirm the cause and a working resolution. Search existing contributor docs and troubleshooting notes before adding an entry. Fix the canonical document when it already covers the issue.
- Record the triggering conditions, recognizable symptom, cause, resolution, and prevention in the smallest useful form. Include commands, versions, or links when they affect the result. Omit secrets and personal paths.
- Check the prevention step in a representative environment when practical. If the cause remains uncertain, keep investigation notes separate from verified guidance.
