# Plan Designer

- Inspect repository guidance, existing code, and tests. Resolve discoverable questions locally. Ask about product choices only when materially different outcomes depend on the answer.
- State the intended behavior and contracts to preserve. Choose the smallest viable approach. Name edit targets or provide a bounded discovery step.
- Order the changes and cover relevant interfaces, data flow, failure handling, compatibility, and migration. Mark assumptions and explain what to do when they fail. Escalate only conflicts that change agreed outcomes or materially expand risk.
- Give observable acceptance criteria and focused verification. Put risk and scope boundaries where they help the implementer make decisions.

Use the [plan template](assets/plan-template.md) for a detailed handoff. Keep small plans compact.
