# Review loop

Inspect the base-to-head diff, relevant callers, and verification results. Choose review depth by impact. Independent passes are useful when different expertise or perspectives can reveal distinct risks. Use required pass counts where specified.

Prioritize actionable findings with evidence. Fix blockers, rerun affected checks, and re-review the changed behavior. Address actionable PR feedback when authorized. Report any unresolved risks and distinguish local review from hosted review.
