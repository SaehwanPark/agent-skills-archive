# Wayback Link Fallback

1. Check the live source. When an archived version is needed, look up the original URL using a narrow date or version window.
2. Open a relevant capture. Verify the claimed content, displayed date, and source URL. Reject soft errors, login pages, unrelated redirects, and captures missing the evidence. Use [capture lookup and replay](references/captures-and-links.md) for CDX, raw replay, and archived links.
3. Cite the snapshot with its capture date and material limitations. Verify present-day claims with a current authoritative source. If the archive is insufficient, try an official versioned page, tag, or release artifact.
